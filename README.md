# Operation: Battleship // Narxoz Incubator 2026

Классический «Морской бой», переосмысленный в эстетике хакерского терминала и SOC-дашборда (Security Operations Center). Проект разработан специально для второго этапа отбора в Narxoz Incubator 2026.

## Идея и концепт
Мне хотелось уйти от заезженной стилистики «школьной тетрадки в клетку». Вместо этого я перенес игру в привычную для себя среду: мониторинг логов, сканирование портов и анализ уязвимостей. 

В этой версии вы не просто ставите корабли — вы разворачиваете сетевую инфраструктуру. Вы не стреляете по квадратам — вы проводите пентест целевой сети, пытаясь положить серверы противника до того, как он обрушит ваши.

## Реализованный функционал (Уровни «Средний» + «Великий»)

Проект представляет собой полноценное Single Page Application (SPA), работающее без перезагрузки страницы:

*   **Три уровня защиты цели (AI):** 
    *   `Script Kiddie` (Легкий) — бьет случайным образом.
    *   `SysAdmin` (Средний) — добивает уязвимые узлы при обнаружении.
    *   `Hacker` (Сложный) — сканирует сеть «шахматкой» и использует алгоритм поиска, минимизируя лишние запросы.
*   **Игровая механика:** Строгое соблюдение правил. Корабли не соприкасаются, вокруг потопленных узлов автоматически блокируются «мертвые зоны». **Важно:** ход передается сопернику *только при промахе* (Timeout), при попадании (Critical Error) атака продолжается.
*   **Статистика и сессии (Профиль):** Весь прогресс, логи боев, точность (процент попаданий) и винрейт сохраняются в `LocalStorage`. При обновлении страницы бой не сбрасывается.
*   **Бизнес-модель (ROOT ДОСТУП):** Реализован прототип PRO-подписки с экраном оплаты (в безопасном тестовом режиме) для демонстрации монетизации продукта.

## Подход к разработке (Tech Stack & AI)

Проект написан на чистом стеке: **HTML5, CSS3, Vanilla JavaScript**. Без тяжелых фреймворков (React/Vue) — только нативный код, чтобы интерфейс работал максимально быстро.

В работе я использовал гибридный подход:
1.  **Алгоритмы и логика:** Механика расчета координат, поиск добивания для бота и правила смены хода контролировались и корректировались вручную.
2.  **Vibe Coding (AI-инструменты):** Для создания SPA-архитектуры (переключение экранов Главная/Атака/Профиль/PRO без перезагрузки) и стилизации под кибер-терминал я активно применял ИИ-ассистентов (Claude / ChatGPT). Это позволило сфокусироваться на пользовательском опыте (UX) и бизнес-логике, делегировав рутину CSS-верстки нейросетям.

## Как запустить

Игра уже задеплоена и работает прямо в браузере.
**Рабочая ссылка:** (https://zhdreamerr.github.io/Battleship/#home)

1. Перейдите по ссылке (работает и с телефона, и с ПК).
2. Нажмите «Начать атаку».
3. Выберите уровень сложности, нажмите «Авторасстановка: моя сеть» и вступайте в бой!
